# City building sets — credits

The four building set GLBs in this directory (`ny.glb`, `night.glb`,
`lpcity.glb`, `cc.glb`) were extracted from CC-BY 4.0 Sketchfab packs by
`scripts/extract_buildings.js` and their textures converted to KTX2/ETC1S
GPU textures by `scripts/ktx_convert.js` (gltf-transform + KTX-Software).

Per-building attribution (including the source pack and node of each
building) lives in `manifest.json`. Pack-level attribution:
